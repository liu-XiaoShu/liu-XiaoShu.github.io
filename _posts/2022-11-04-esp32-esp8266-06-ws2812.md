## WS2812 全彩 LED 简介

所谓基于 WS2812B 的灯珠，是将控制芯片封装进全彩 LED，配合单线协议即可独立控色。

### 封装与引脚

![图1 WS2812 全彩LED灯珠封装实物图](/assets/img/posts/esp32-esp8266-06-ws2812/img-01.png)

![WS2812 全彩LED灯珠封装尺寸及引脚图](/assets/img/posts/esp32-esp8266-06-ws2812/img-02.png)

- **VDD / VSS**：电源与地
- **DIN**：数据输入
- **DOUT**：级联输出（接下一颗灯的 DIN）

将上一颗的 **DOUT** 接到下一颗的 **DIN** 即可串联。

### 控制协议要点

1. 每个像素用 **24 bit**（G、R、B 各 8 bit）表示颜色。
2. 数据按 **G7→G0→R7→R0→B7→B0** 顺序逐 bit 发送。
3. 单线 NRZ 编码：用高电平脉宽区分 0/1，固定 bit 时长以便同步。

## Micropython 驱动示例

### neopixel 库

```python
import neopixel
```

文档：[neopixel 库说明](https://doc.bpi-steam.com/zh_CN/stable/mPython/docs/library/micropython/neopixel.html)

### 接线

| 开发板 | WS2812 |
| --- | --- |
| GND | VSS |
| 3V3 | VCC |
| GPIO13 | DIN |

### 示例代码

```python
import neopixel
from machine import Pin
from utime import sleep_ms

GPIO_IN = Pin(13)   # 控制信号输入引脚
LED_NUM = 64        # LED 灯数量

# NeoPixel(pin, n, bpp=3, timing=0)
# timing=0 → 400KHz；timing=1 → 800KHz
LED = neopixel.NeoPixel(pin=GPIO_IN, n=LED_NUM, bpp=3, timing=0)
LED.fill((255, 0, 0))   # GRB 顺序，全部填红
LED.write()
sleep_ms(500)
LED[0] = (255, 255, 255)  # 第一颗设为白色
LED.write()
```
