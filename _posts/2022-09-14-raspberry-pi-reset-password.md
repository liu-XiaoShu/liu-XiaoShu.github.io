## 📌 简介

树莓派 4B 长期不用忘记密码时，可通过 **修改 `/etc/shadow`** 恢复登录。思路是在另一台同系统机器上编辑 SD 卡或硬盘中的 shadow 文件。

---

## 树莓派：忘记密码怎么办

### 背景

树莓派 4B 因长期闲置忘记登录密码，可在 **同系统** 的电脑上编辑 shadow 文件重置。

### 操作步骤

1. 在装有 **相同系统**（如 Ubuntu）的电脑上，用户密码哈希位于：

```bash
sudo vim /etc/shadow
```

2. 找到对应用户行，格式类似：

```text
test:密码加密后的字符:::
```

3. 将树莓派 SD 卡通过读卡器接到该电脑，打开 SD 卡根文件系统中的 `/etc/shadow`。
4. 用步骤 2 中 **已知密码** 那台机器上对应用户的哈希字段，替换树莓派 shadow 里同用户行的哈希。
5. SD 卡插回树莓派，用步骤 2 那台机器的密码登录。
6. 登录成功后，再用 `passwd` 设置新密码。

> **注意**：两台设备系统需一致（例如都是 Ubuntu），否则哈希算法/格式可能不兼容。若烧录的是 Raspberry Pi OS，最好在同样系统的环境下修改。

---

## Linux 通用思路

与树莓派类似，区别是介质从 SD 卡换成 **硬盘**：拆下硬盘挂载到另一台同系统电脑，编辑其 `/etc/shadow` 中目标用户哈希即可。

**请勿用于未授权访问他人设备。**
