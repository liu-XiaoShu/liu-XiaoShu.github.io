##### 树梅派登入忘记密码问题

* * *

###### 我的树梅派 4B 因"吃灰"很久了导致登入密码忘记，怎么解决呢?

###### 解决步骤

  1. 我的树梅派之前烧入的是 ubuntu 系统，我首先找到一台装有 ubuntu 系统的电脑，研究发现用户的密码存在如下位置


    
    
    sudo vim /etc/shadow
    

  2. 在 shadow 找到 ubuntu 系统的电脑用户名，比如我的用户名是 test,，密码是 00000, 会发现如下字符:


    
    
    test:密码加密后的字符：：
    

  3. 拔出树梅派的 sd 卡，使用读卡器插入 ubuntu 系统的电脑，同样方式打开 sd卡 中的 shadow 文件，把步骤2 的密码加密后的字符替换到这里，这样密码就被改成了， ubuntu 系统的电脑的密码，比如 00000
  4. 修改完成 shadow 文件后，重新插入树梅派，就可以使用 ubuntu 系统的电脑密码登入
  5. 使用该方法登入后，就可以重新设置密码了



注意: 为了保证能顺利修改，请使用相同系统的两台设备，假如树梅派烧入的是树美派官方系统，那最好使用安装树梅派系统一致的树梅派修改，保证加密字符能顺利识别

##### Linux 登入忘记密码问题

* * *

###### 推测和上述修改树梅派的密码一致，唯一区别就是不是取出 sd 卡，而是取出硬盘，重新挂载在另一台相同系统的电脑上修改，核心就是替换 shadow 文件中密码字符．**注意别做违法的事情！！！！**
